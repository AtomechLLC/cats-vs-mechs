**The disable contract, written as an `if and only if` and implemented as one.** An action button on
this grid is disabled **iff**:
  (a) `App.model.affordability(fgCaster(state, side), action)` reports a requirement term whose
      `have < need` — requirements read on the CASTER SIDE, which is the shipped machinery's own
      stated rule and not a change this plan makes; **or**

      `fight[side].ap − spokenFor(side) + (the cost this row's own standing declaration already

      action frees the one it replaces, and without it a unit's own declared action would disable
