<the_line_this_phase_walks>
**This is the load-bearing decision of the phase**, so it is written into the file beside the op, as
a table, in the register `resetToDefaults` and `#reset-ask` both use for a ruling with alternatives.

> **Advance may restate; it may never decide.** Every number Advance writes must be one the student
> put on the board themselves — an action's own declared cost, an action's own declared terms, the
> unit they named as performer, the unit they named as the one it points at. The moment Advance would
> have to *choose* between two admissible readings, it stops and the table rules.

**Advance DOES:** subtract the declared action's own `cost` from the side's pool; apply the action's
own `xf` terms to the units the student named; split a negative delta on a token in `DAMAGE_KEYS`
across shield then health; clamp every write through `int()`; record what it did; advance the round
and clear the declarations.

**Advance does NOT:** choose an action; choose a unit for an action to point at; decide whether a
relationship applies (`REFERENCE.beats` has no consumer in `[S05]` and gains none); decide whether an
effect fires (`keywords` has no writer and gains none); decide whether a unit is dead (`alive` is
stored, never inferred); refuse a declaration a side cannot pay for; refill a shield; **decide the
fight is over.** Nothing announces an outcome, names a side, or renders a terminal state beyond what
is already true on the board (D-26).

Write that table into the file. It is the thing most likely to erode under implementation pressure and
a plan file is not where it will be read.
</the_line_this_phase_walks>
