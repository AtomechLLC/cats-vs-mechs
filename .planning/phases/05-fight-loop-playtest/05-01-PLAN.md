<the_line_this_phase_walks>
This plan changes no behaviour a student can see. It changes what the build refuses.

The standing rule at `tests/selftest-node.cjs:4726` binds it: **a widening must measure its false
positives first.** The artifact is roughly a megabyte of deliberate prose and every comment in it is
Layer A material. A word list widened without that measurement is a build that goes red on a sentence
somebody wrote two phases ago, which is how a gate stops being trusted.

And the gate is a floor, not a ceiling. Closing the mechanical hole does not make the remaining
clean-but-evaluative vocabulary shippable — `contested`, `one-sided`, `blowout`, `even`, `close`,
`tight` all pass and all must still stay off the page. That is a written rule, not a regex, and it
belongs in the comment beside the lists.
</the_line_this_phase_walks>
