policed the moment it writes a word.

turns the promise into a CI gate, in the file `.github/workflows/pages.yml` already runs.
Output: `VERDICT_WORDS` (Layer A) + a literal-only scan (Layer B) + a rendered-page walk (Layer C),
all in `tests/selftest-node.cjs`; one reworded comment in `cats-vs-mechs.html`.
