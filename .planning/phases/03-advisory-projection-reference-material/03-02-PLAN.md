<the_model_stated_exactly>
D-02 through D-07, restated as arithmetic. Every line was executed against the shipped derivations.

    perTurn(A)        = App.model.factionDps(A)   = min(A.ap, A.units.length) * bestDamage(A)
    hit(A)            = App.model.bestDamage(A)   = max over A.actions of a.dmg
    targetEhp(T)      = App.model.factionEhp(T)   = sum over T.units of (maxHp + shield)
    soakTotal(T, hit) = sum over T.units of ceil(unitEhp(u) / hit) * hit      -- D-04
    fast(A,T)         = ceil(targetEhp(T) / perTurn(A))                       -- D-03
    slow(A,T)         = ceil(soakTotal(T, hit(A)) / perTurn(A))

`slow >= fast` always, because `soakTotal >= targetEhp` term by term. An exhaustive sweep over
hp 1–12 × shield 0–6 × hit 1–6 × ap 1–6 × units 1–6 — 18,144 combinations — produced 0 inversions
and 0 non-finite results with the guards below in place.

**The per-unit ceiling is the whole point.** A mixed roster wastes a different amount on each unit;
a faction-total ceiling silently under-reports it. Cats at 1/2/3 hp repeated give eHP 18 and soak 27,
not soak 18.
</the_model_stated_exactly>

<the_two_guards>
Both were reproduced through shipped ops, not reasoned about.

| Case | How it is reached | Raw arithmetic | Required behaviour |
|---|---|---|---|
| `perTurn === 0` | `App.ops.setFactionAp(side, 0)` — the stepper's floor is 0 | `ceil(27/0)` → `Infinity` → **"≈Infinity turns"** | `turnsToWipe` returns `null` |
| `hit <= 0` | `bestDamage === 0` — a faction whose actions are all status effects | `ceil(9/0) * 0` → `NaN` → **"≈NaN turns"** | `soakTotal` returns `0`, refusing **before** the reduce |
| both at once | target at 0 health AND attacker at 0 AP | `ceil(0/0)` → `NaN` | the `perTurn` guard must run **FIRST**, before any division |

**Ordering is load-bearing.** Guard `perTurn <= 0` before computing anything else. A guard placed
after the eHP read still divides `0/0`.

**A clamp is not an option.** `dps || 1` renders "≈27 turns" for a side that cannot attack, which is
a lie. `null` and a copy branch is not. The copy branch itself belongs to plan 03-03, never here —
`[S02]`'s banner excludes formatting, and a "≈" belongs to the page.
</the_two_guards>
