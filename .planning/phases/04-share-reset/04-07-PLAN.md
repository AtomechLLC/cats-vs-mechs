<objective>
Finish the surface: take a classmate's code, and ask before discarding a board.

Both halves are smaller than they look, and the reason is worth stating because the ROADMAP's own
plan sketch implies otherwise. **`App.ops.resetToDefaults()` already exists** (`:3230`), is already
dispatchable (`:4181`) and is already wired to a button (`:9391`). Research measured its behaviour
against the live artifact: it adds exactly one undo entry, one Ctrl+Z restores the build
byte-for-byte, and it clears the fight slice. **This plan writes a surface for the op that ships, not
the op.** And plan 04-04 already wrote the whole write path a pasted code takes, guards and all; this
plan reads a field, dispatches, and turns a token into a sentence.

The words are the work. `decode` hands back one of four tokens and the page owns every sentence a
student reads — the same split `turnsToWipe` and `turnsText` have drawn since Phase 3. Four tokens
exist because "corrupted", "truncated", "wrong version" and "not a build code" are four different
things a student can act on differently, and collapsing them into one message throws away the only
diagnosis this tool can offer. Plan 04-03 proved the tokens. This plan writes the sentences, and a
check holds them apart.

Purpose: SHARE-02, SHARE-03's on-screen half, and SHARE-06.
Output: a load path, a confirmation in front of an unchanged op, and the phase's own acceptance run.
