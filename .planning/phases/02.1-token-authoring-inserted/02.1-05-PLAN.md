<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| A student's press -> `[S07.1] routeUi` -> the seam or `[S05] dispatch` | The routing decision itself is a boundary: a UI act that reaches `dispatch` shows an error panel; a state act that stops at the seam writes nothing. |
| `#tok-pick-name` -> `App.ops.renameTokenType` | The first place in this project where arbitrary student text becomes a committed value. |
| `dlg.dataset.tok` -> `App.ops.dispatch({ tokenId })` | An attribute read off the page becomes the key that indexes the vocabulary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-25 | Elevation of privilege | `selectTokenType` routed through `[S05] dispatch` | mitigate | It is registered in `UI_HANDLERS` and claimed by `UI_ACTS`, never given a `case`. Enforced by `grep -c "case 'selectTokenType'" == 0` and by the shipped must-not-regress grep on `case 'openTokenPicker'`. |
| T-02.1-26 | Tampering / EoP | `dlg.dataset.tok` reaching `build.tokens` as a key | mitigate | Every op it reaches (`renameTokenType`, `removeTokenType`, `setTokenStyle`) runs `requireTokenId` before indexing anything. The page-side value is never trusted; it is re-gated at the `[S05]` boundary, which is where the guard belongs. |
| T-02.1-27 | Tampering | A lone surrogate reaching state from a 30-emoji paste | mitigate | `clampTokenName` on the input event cuts on the code-point array; `requireTokenName` refuses `\p{Cs}` as a backstop. Asserted for `Array.from` length and for `encodeURIComponent` not throwing. |
| T-02.1-28 | Tampering | Markup injection through the name field | mitigate | The value reaches state as a string and reaches the page only through `textContent` and `input.value`.
