    The script must number these checks separately. **Check 1 is the topbar collapse and it stands
    alone**, per D-06:

    1. **The topbar collapse (D-05 / D-06).** The bar now carries one token button where four stood.
       Is the bar better than it was? Is "Tokens" the right label? Is the picker obviously where a
       student goes to change how a token looks? This is a yes/no on a change that was built ahead of
       its approval; a "no" reworks the topbar, the dialog and eight harness checks, so it deserves
       its own answer rather than a nod inside a general look-over.
    2. **A zero tally collapses its line.** Create a unit-scope type. Every unit card must show
       NOTHING for it — not an empty box beside a live label. Nudge one unit's tally to 1 and the line
       appears. This is the `[hidden]` cascade rule, which has no layout engine in the Node gate and
       fails OPEN as 144 empty labelled boxes.
    3. **Escape inside the name field.** With the picker open, click into the name field, type, press
       Escape. The text must revert and **the dialog must stay open**. Press Escape again with focus
       anywhere else in the dialog: it must close, as it did in Phase 2.
    4. **`maxlength` on a real input.** Type past 24 characters in the name field — it should stop.
       Then paste 30 emoji into it: the value must end up 24 emoji, and pressing Enter must not raise
       an error panel. (`maxlength` counts code units and the cap counts code points, so these two
       are deliberately different tests.)
    5. **An 11-row list on the projector.** With six student-made types created, is the picker's list
       legible from the back of the room? Record the display and the viewing distance — Phase 2's
       rehearsal closed this by aggregate observation with neither written down, and this phase
       inherits that gap rather than closing it by assertion.
    6. **A rename reaches everywhere.** Rename Health to Vigor. The picker list row, the picker
       heading and every board label must all say Vigor. Undo must put Health back everywhere.
    7. **A refusal reads like a sentence.** Force a refusal a student could plausibly hit — a name of
       spaces, or removing a built-in — and read the message. It must name what was refused in plain
       words, not read like a stack trace.
    8. **The end-to-end story.** Invent a type ("Poison ☠", circle, violet), tally it on two cats,
       see the tokens on the board, remove it, press Ctrl+Z, and watch the type and both numbers come
       back together.
    9. **Nothing regressed.** Steppers, delta typing, arrow keys, press-and-hold, add and remove unit,
       and the appearance swatches all still behave as `02-HUMAN-UAT.md` recorded them.

    For each check the script must state the exact steps and the expected outcome, so the human is
    confirming a prediction rather than forming an opinion from scratch.
