providing, and give every token record the display name ALLOC-10 needs.

constants), adds the `[S05] OPS` guard helpers every later write path will call, rewires

prototype-pollution defence today. Replacing membership validation with shape validation is the
security-sensitive edit of the whole phase, and it must land first and land proven.

it and a `name` on every token record.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `[S07]` page -> `[S05]` ops | A `data-*` attribute read off the page is a caller-supplied key. It reaches `App.ops.dispatch` and, from this phase on, can name a token type. |
| `[S05]` ops -> `build.tokens` | A caller-supplied key is about to index a plain object. This is where CR-02 happened and where both measured corruption shapes live. |
