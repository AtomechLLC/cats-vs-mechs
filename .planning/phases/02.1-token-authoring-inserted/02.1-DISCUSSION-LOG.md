## Claude's Discretion

Every area in this phase. Summarised:

- **Tally scope (D-01–D-04):** the student picks per-unit or per-faction at creation; fixed
  afterwards; tallies sparse and defaulting to zero. Chosen partly because both render sites
  already exist in `[S06]`, which makes the flexible option nearly as cheap as a forced one.
- **Reaching the editor (D-05–D-08):** the four topbar buttons collapse into one "Tokens" button
  opening a list-plus-editor picker. Bounds the topbar permanently; no board-side control.
- **Naming (D-09–D-14):** the name is a display label, the generated id stays the identity;
  built-ins are renamable; names need not be unique; 24-char cap on an allowlisted character set;
  ids generated from a sequence, never derived from user text; id-shape validation replaces the
  `TOKEN_IDS` membership allowlist and must still refuse prototype keys and built-in collisions
  by name.
- **Removal (D-15–D-18):** built-ins cannot be removed; removing a custom type takes its tallies
  as one undo entry; no confirmation dialog, because undo already covers it; cap of 6 custom
  types, treated as a Phase 4 tuning dial.
