<objective>
Turn the per-type appearance dialog into a list-plus-editor that shows every token type, and fix the
repaint gate that is blind to a name and to membership.

Purpose: D-05 says the picker shows EVERY type, built-in and student-made, as a selectable list with
the editor beside it. Research measured that the shipped signature
(`id + '/' + shape + '/' + color + '/' + glyph`) changes for none of the things this phase adds — a
rename left `dlg.dataset.sig` and the heading untouched, and creating a type moved nothing. A
list-plus-editor built on that signature is born broken.

Output: the dialog's new static nodes, their styles, `[S06.2]` rebuilt around a whole-vocabulary
fingerprint, `TOKEN_NAMES` deleted, and the harness stub grown to match. The topbar still carries its
four buttons and the handlers are still the shipped ones — plan 02.1-05 changes both, together,
because they change together or the picker opens on `undefined`.
</objective>
