<open_questions_resolved>
**Curated glyph set versus free-text entry — RESOLVED: curated.** 02-CONTEXT.md's
`<deferred>` list left the picker's own vocabulary open and asked the planner to treat it as
open. Three reasons decide it, two of them measured:

1. **Phase 4's codec cost, measured.** `encodeURIComponent` lengths: a plain emoji is 12
   characters, a variation-selector emoji is 21, a ZWJ sequence is 30. Five token types with
   free-text emoji is 60–150 characters against SHARE-04's 512-character design budget —
   12–29% of the entire build code spent on decoration. A curated set of at most 32 glyphs
   indexes to **one character** each. D-12 already commits this to ride in the build code.
2. **The state contract.** `[S03]`'s banner promises integers and short enums; `int()`,
   `requireSide` and `UI_KEYS` all assume it. An arbitrary student string in `build` is a new
   class of value in a contract three phases now depend on.
3. **D-10 becomes enforceable.** With a curated set every offered glyph can be verified as a
   single code point that renders on Windows, macOS and Linux. With free text a student pastes
   a just-released emoji and it renders as a tofu box on the projector — the exact failure D-10
   exists to prevent.

If free text is ever wanted, it belongs behind a Phase 4 decision about codec cost, not here.
</open_questions_resolved>
